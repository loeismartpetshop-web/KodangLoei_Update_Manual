อัปเดตระบบแจ้งเตือน LINE และบิลออเดอร์

อัปเดตระบบแจ้งลูกค้าผ่าน LINE ให้ครบขึ้น ตั้งแต่เปิดบิล แก้ออเดอร์ ไปจนถึงเปลี่ยนสถานะจัดส่ง

⌄
ส่งบิลหลังสั่งซื้อลูกค้าสั่งซื้อแล้ว LINE ส่งบิลออเดอร์แรกกลับให้อัตโนมัติ
แก้จำนวนแล้วตีบิลใหม่กรณีสต๊อกจริงไม่พอ แอดมินปรับจำนวนได้ แล้วระบบส่งบิลยอดใหม่ให้ลูกค้าทันที
แจ้งสถานะเรียลไทม์เปลี่ยนเป็นรอคอนเฟิร์ม / กำลังจัดส่ง / ส่งแล้ว แล้วส่งการ์ดแจ้งลูกค้าใน LINE
เวลาในบิลอัปเดตใหม่บิลแจ้งเตือนใช้เวลาล่าสุดของเหตุการณ์นั้น ไม่ยึดเวลาจากบิลแรก
ลดปัญหาออเดอร์ซ้ำเพิ่มการกันส่งซ้ำช่วงกดสั่งซื้อ เพื่อไม่ให้ชีตและแอพแอดมินมีรายการซ้อน
ปรับการ์ดให้แก้ต่อได้เพิ่มโครงการ์ดบิลแก้ไขและสีสถานะ เพื่อให้ปรับหน้าตาบิลได้ง่ายขึ้น
ชีตแยกปลีก / ส่งเพิ่มแท็บ Orders_ปลีก และ Orders_ส่ง สำหรับดูแยกช่องทาง โดยออเดอร์รวมยังเป็นต้นทางหลัก
Dashboard แอดมินเพิ่มภาพรวมยอดขาย จำนวนออเดอร์ สถานะออเดอร์ รายการรอดำเนินการ และเวลาอัปเดตล่าสุด
ดูสต๊อกง่ายขึ้นมีหน้าสต๊อกเหลือน้อย แยกใกล้หมด / หมดแล้ว / ทั้งหมด พร้อมจำนวนคงเหลือรายสินค้า

ชีตออเดอร์ แยกแท็บปลีก / ส่ง

เพิ่มแท็บ Orders_ปลีก และ Orders_ส่ง เพื่อดูออเดอร์ตามช่องทางได้เร็วขึ้น แต่เวลาจะลบหรือแก้รายการจริงให้ยึดจากออเดอร์รวมก่อน เพราะเป็นข้อมูลต้นทางที่ระบบใช้ซิงก์ไปยังแท็บแยก

Dashboard ภาพรวมในแอพแอดมิน

หน้าแอดมินมีสรุปยอดขายวันนี้, ออเดอร์วันนี้, ยอดขายเดือนนี้, งานรอจัดการ, สินค้าใกล้หมด, สถานะพร้อมเคลียร์ และจำนวนออเดอร์ตามสถานะ เช่น ออเดอร์ใหม่ รอคอนเฟิร์ม กำลังจัดส่ง ส่งแล้ว ยกเลิก

สต๊อกสินค้า ดูจำนวนคงเหลืออย่างง่าย

หน้าสต๊อกแสดงจำนวนสินค้าทั้งหมด และรายการสินค้าแต่ละตัวพร้อมจำนวนคงเหลือ เหมาะสำหรับเช็กของหน้าร้านแบบเร็ว ๆ

ตัวกรองสต๊อก ใกล้หมด / หมดแล้ว / ทั้งหมด

มีตัวกรอง ใกล้หมด, หมดแล้ว และ ทั้งหมด ถ้าไม่มีสินค้าต่ำกว่าเกณฑ์ ระบบจะแสดงข้อความว่าไม่มีสินค้าติดต่ำ

07

โครงข้อมูลบนชีต: Channel + AdminUsers

เพิ่มข้อมูลช่องทางออเดอร์ และเปลี่ยนระบบล็อกอินให้ควบคุมจากชีต ไม่ใช้รหัส 1234 ในโค้ดเหมือนเดิม

เพิ่มแล้ว

Orders เพิ่มคอลัมน์ Channel

สถานะตอนนี้: เก็บ Channel แล้ว เช่น “ปลีก” หรือ “ส่ง” แต่หน้าออเดอร์บนชีตยังเป็นออเดอร์รวม ยังไม่ได้จัดหน้าแยกปลีก/ส่งในชีต

AdminUsers Login ตามสิทธิ์ในชีต

เปลี่ยนจากเดิม: เดิมใส่ชื่ออะไรก็ได้ + รหัสจากโค้ด 1234 ตอนนี้ต้องใช้ Username/Password/Role ตามชีตเท่านั้น

ภาพรวมระบบ

  • ระบบใหม่ช่วยแยกร้านปลีก/ส่งโดยไม่ต้องสร้างเว็บซ้ำ
  • หลังบ้านมีสิทธิ์และช่องทางชัดเจน ลดออเดอร์ปนกัน
  • โหมดปิดปรับปรุงช่วยลดความเสี่ยงช่วง Dev แก้ระบบ

ระบบที่จะทำต่อ

  • ส่งบิลใหม่ที่เเก้ไขกลับ LINE ลูกค้า อัตโนมัติหลังแก้จำนวนสินค้า
  • ส่งบิลสถานะเเจ้งเตือนไปยัง LINE ลูกค้า อัตโนมัติหลังแก้สถานะ เช่น ส่งเเล้ว-กำลังจัดส่ง
  • ระบบกันสเเปมบอท
  • ระบบเปลี่ยนภาพเเบรนเนอร์สำหรับ ร้านค้าส่ง
  • การเเก้ไขสี เหลือง>ร้านขายส่ง/ชมพู>ร้านขายปลีก
  • การเเก้ช่องลูกค้าในหน้า ชำระเงิน ในเเต่ละร้าน จากเดิม จะเเสดงทั้งลูกค้าประจำเเละลูกค้าทั่วไป เเก้เป็น ร้านส่งก็จะมีเเค่ลูกค้าประจำที่มีในระบบ หรือ อาจจะมีลูกค้าใหม่ร่วมด้วย เเละ ร้านปลีกก็จะมีเเค่ลูกค้าทั่วไป การชำระ ของเเต่ละร้านตัดส่วน COD ออกเเละให้ชำระโอนจ่ายทันที เว้น เเค่มารับที่ร้านจะต้องจ่าย COD หรือจ่ายกับพนักงานโดยตรง
  • เพิ่มภาพริสเมณูในเเต่ละร้าน คนละสไตล์
  • จัดระเบียบหน้าออเดอร์ในชีตให้แยกปลีก/ส่งชัดขึ้น เเละตัดระบบส่วนเกินออก
  • ย้ายฐานไปยัง Line OA จริง
  • ทดสอบ flow จริงตั้งแต่ Rich Menu → สั่งซื้อ → หลังบ้าน → ชีต
