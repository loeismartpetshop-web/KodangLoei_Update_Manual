02

โหมดปิดปรับปรุง + ล็อกหลังบ้าน

ออกแบบไว้กันช่วง Dev กำลังแก้ระบบ แล้วมีแอดมินรองเข้ามาแก้ภาพสินค้า ชื่อสินค้า หรือหมวดหมู่ชนกัน

เพิ่มแล้ว

Owner Control เปิด/ปิดจากหลังบ้าน

User Notice แจ้งเตือนทันที

ลูกค้า

  • เห็นหน้าปิดปรับปรุงทันที
  • ลดความเสี่ยงสั่งซื้อระหว่างแก้ระบบ

แอดมินรอง

  • ถูกล็อกไม่ให้แก้สินค้า/ภาพ/หมวดหมู่
  • ลดโอกาสข้อมูลทับกัน

แอดมินสูงสุด

  • เข้า bypass ได้ด้วย Role owner
  • ใช้ตรวจหรือปลดล็อกหลังบ้าน

  • รอทำต่อในเฟสถัดไป
07

โครงข้อมูลบนชีต: Channel + AdminUsers

เพิ่มข้อมูลช่องทางออเดอร์ และเปลี่ยนระบบล็อกอินให้ควบคุมจากชีต ไม่ใช้รหัส 1234 ในโค้ดเหมือนเดิม

เพิ่มแล้ว

Orders เพิ่มคอลัมน์ Channel

สถานะตอนนี้: เก็บ Channel แล้ว เช่น “ปลีก” หรือ “ส่ง” แต่หน้าออเดอร์บนชีตยังเป็นออเดอร์รวม ยังไม่ได้จัดหน้าแยกปลีก/ส่งในชีต

AdminUsers Login ตามสิทธิ์ในชีต

เปลี่ยนจากเดิม: เดิมใส่ชื่ออะไรก็ได้ + รหัสจากโค้ด 1234 ตอนนี้ต้องใช้ Username/Password/Role ตามชีตเท่านั้น

ภาพรวมระบบ

  • ระบบใหม่ช่วยแยกร้านปลีก/ส่งโดยไม่ต้องสร้างเว็บซ้ำ
  • หลังบ้านมีสิทธิ์และช่องทางชัดเจน ลดออเดอร์ปนกัน
  • โหมดปิดปรับปรุงช่วยลดความเสี่ยงช่วง Dev แก้ระบบ

ระบบที่จะทำต่อ

  • ส่งบิลใหม่ที่เเก้ไขกลับ LINE ลูกค้า อัตโนมัติหลังแก้จำนวนสินค้า
  • ส่งบิลสถานะเเจ้งเตือนไปยัง LINE ลูกค้า อัตโนมัติหลังแก้สถานะ เช่น ส่งเเล้ว-กำลังจัดส่ง
  • ระบบกันสเเปมบอท
  • ระบบเปลี่ยนภาพเเบรนเนอร์สำหรับ ร้านค้าส่ง
  • การเเก้ไขสี เหลือง>ร้านขายส่ง/ชมพู>ร้านขายปลีก
  • การเเก้ช่องลูกค้าในหน้า ชำระเงิน ในเเต่ละร้าน จากเดิม จะเเสดงทั้งลูกค้าประจำเเละลูกค้าทั่วไป เเก้เป็น ร้านส่งก็จะมีเเค่ลูกค้าประจำที่มีในระบบ หรือ อาจจะมีลูกค้าใหม่ร่วมด้วย เเละ ร้านปลีกก็จะมีเเค่ลูกค้าทั่วไป การชำระ ของเเต่ละร้านตัดส่วน COD ออกเเละให้ชำระโอนจ่ายทันที เว้น เเค่มารับที่ร้านจะต้องจ่าย COD หรือจ่ายกับพนักงานโดยตรง
  • เพิ่มภาพริสเมณูในเเต่ละร้าน คนละสไตล์
  • จัดระเบียบหน้าออเดอร์ในชีตให้แยกปลีก/ส่งชัดขึ้น เเละตัดระบบส่วนเกินออก
  • ย้ายฐานไปยัง Line OA จริง
  • ทดสอบ flow จริงตั้งแต่ Rich Menu → สั่งซื้อ → หลังบ้าน → ชีต
