อัปเดตล่าสุด

ที่อยู่มาตรฐาน + พิกัด GPS ลูกค้า / ปุ่มรับทราบแจ้งแอดมิน / ลบสรุปยอดรายเดือน

รอบนี้เก็บงานหลังบ้านและประสบการณ์ลูกค้า: เพิ่มช่องที่อยู่มาตรฐานพร้อมจับพิกัด GPS จริงของลูกค้าให้คนส่งกดนำทางได้ตรงจุด, เพิ่มปุ่ม "รับทราบออเดอร์" ให้ลูกค้ากดครั้งเดียวเพื่อเด้งแจ้งแอดมินใน LINE OA, ลบระบบสรุปยอด/แดชบอร์ดที่ไม่ใช้ออกทั้งฝั่งชีตและแอปแอดมิน และมีสวิตช์สำรอง "ปิดราคาทั้งหมดเป็น 0 บาท" เผื่อกรณีฉุกเฉิน

⌄
1. ช่องที่อยู่มาตรฐาน (บ้านเลขที่/หมู่/จุดสังเกต)เพิ่มช่องกรอก "บ้านเลขที่ / หมู่ / จุดสังเกต" แยกจากช่องตำบล-อำเภอ-จังหวัด-รหัสไปรษณีย์ เพราะพิกัดจากแผนที่บอกได้แค่ระดับตำบล การแยกช่องนี้ทำให้ที่อยู่ครบถ้วนเป็นมาตรฐานสำหรับจัดส่ง
2. จับพิกัด GPS จริงของลูกค้าตอนลูกค้ากดปุ่มใช้ตำแหน่งหรือเลื่อนหมุดบนแผนที่ ระบบเก็บพิกัดจริงติดไปกับออเดอร์ ไม่ใช่แค่ข้อความที่อยู่ ทำให้รู้ตำแหน่งบ้านได้แม่นขึ้น
3. ปุ่มนำทาง GPS ในหน้าสถานะหน้าเช็กสถานะออเดอร์มีปุ่ม "นำทางไปตำแหน่ง GPS ลูกค้า" กดแล้วเปิด Google Maps นำทางไปพิกัดนั้นตรง ๆ ให้คนส่งหาบ้านง่ายขึ้น
4. ปุ่มรับทราบออเดอร์ (แจ้งแอดมิน)หลังบอทส่งบิล มีปุ่ม "รับทราบออเดอร์" ให้ลูกค้ากดครั้งเดียว (กดแล้วปุ่มหายเอง) เพื่อดันแชทลูกค้าเด้งขึ้นบนสุดและแจ้งเตือนแอดมินใน LINE OA ว่ามีออเดอร์ใหม่
5. บอทไม่ตอบทับเมื่อลูกค้ากดรับทราบ ระบบตั้งใจให้บอทเงียบไว้ ไม่ตอบกลับอัตโนมัติ เพื่อให้ห้องแชทคงสถานะรอตอบให้แอดมินเห็นและตอบเอง
6. ลบสรุปยอดรายเดือนออกจากชีตเอาแถบสรุปยอดรายเดือนและแดชบอร์ดสรุปในชีต Google ออก พร้อมปิดตัวที่สร้างชีตขึ้นใหม่อัตโนมัติทุกวัน โดยไม่กระทบข้อมูลออเดอร์และสต๊อก
7. ลบแดชบอร์ดในแอปแอดมินเอาส่วนสรุปยอด/แดชบอร์ดที่ไม่ได้ใช้ออกจากแอปแอดมิน แต่ยังเก็บตัวนับจำนวนออเดอร์แต่ละสถานะและเครื่องมือ "พร้อมเคลียร์" (ย้ายออเดอร์ที่ส่งแล้วเข้าคลัง) ไว้ครบ
8. สวิตช์ปิดราคาทั้งหมดเป็น 0 บาทเพิ่มสวิตช์สำรองในหลังบ้าน "ปิดราคาทั้งหมดเป็น 0 บาท" เผื่อกรณีฉุกเฉินหรือเหตุไม่คาดฝัน เมื่อเปิดใช้ ระบบจะแสดงราคาสินค้า ตะกร้า ยอดรวม และออเดอร์เป็น 0 บาททั้งหมด
9. ยอดขั้นต่ำ 300 บาทถึงจะสั่งได้ตั้งขั้นต่ำการสั่งซื้อไว้ที่ 300 บาท ถ้ายอดยังไม่ถึง ระบบขึ้นแถบเตือนทันที (เช่น "ขาดอีก ฿258") และปิดปุ่มส่งคำสั่งซื้อไว้จนกว่าจะครบ กันออเดอร์เล็กเกินไป

ที่อยู่มาตรฐาน ช่องบ้านเลขที่/หมู่ แยกชัด

ลูกค้ากรอกบ้านเลขที่/หมู่/จุดสังเกตเอง ส่วนตำบล-อำเภอ-จังหวัด-รหัสเติมจากแผนที่ได้

นำทาง GPS เปิด Google Maps ไปจุดปักหมุดลูกค้า

คนส่งกดปุ่มในหน้าสถานะแล้วเปิด Google Maps นำทางไปจุดที่ลูกค้าปักหมุดจริงได้ทันที (ตัวอย่างเส้นทาง 6.8 กม. ~10 นาที)

รับทราบออเดอร์ ปุ่ม Quick Reply บนบิล (ก่อนกด)

หลังบอทส่งบิล มีข้อความชวนกดและปุ่ม "รับทราบออเดอร์" ให้ลูกค้ากดยืนยันหนึ่งครั้ง

รับทราบแล้ว ปุ่มหายเอง + เด้งแจ้งร้าน (หลังกด)

พอลูกค้ากด ปุ่มหายทันที และมีข้อความ "รับทราบออเดอร์ + รหัสออเดอร์" เด้งเข้าแชทให้ทางร้านเห็น

ขั้นต่ำ 300 บาท ยังไม่ถึงยอด สั่งซื้อไม่ได้

ถ้ายอดไม่ถึง 300 บาท ระบบขึ้นแถบเตือน (เช่น ขาดอีก ฿258) และปิดปุ่ม "ส่งคำสั่งซื้อ" ไว้จนกว่าจะครบ

ปิดราคา 0 บาท สวิตช์สำรองในหลังบ้าน

สวิตช์ "ปิดราคาทั้งหมดเป็น 0 บาท" ในหลังบ้าน เผื่อกรณีฉุกเฉิน/เหตุไม่คาดฝัน เปิดแล้วสินค้า ตะกร้า ยอดรวม และออเดอร์เป็น 0 บาททั้งหมด

Dropdown ธนาคารเลขบัญชี / QR Code + ใบเสนอราคาก่อน-หลังแก้ราคา + ย้าย OA จริงผ่าน

รอบนี้สรุปเฉพาะงานที่เกี่ยวกับการใช้งานจริง: หลังบ้านเลือกธนาคารได้ทั้งแบบเลขบัญชีและ QR Code, ใบเสนอราคาก่อนแก้ราคาและหลังแก้ราคาถูกสร้างใหม่ตามยอดล่าสุด และการย้ายไปใช้งานบน LINE OA จริงผ่านแล้ว

⌄
Dropdown เลขบัญชีหลังบ้านเลือกชื่อธนาคารสำหรับเลขบัญชีได้จากรายการหลัก ได้แก่ กสิกรไทย, ไทยพาณิชย์, กรุงไทย, กรุงเทพ, กรุงศรีอยุธยา และ อื่นๆ สำหรับพิมพ์ชื่อเอง
Dropdown QR Codeส่วนตั้งค่า QR Code ใช้รายการธนาคารแบบเดียวกันกับเลขบัญชี ทำให้ร้านตั้งชื่อธนาคารของ QR ได้ตรงกันและไม่ต้องพิมพ์ซ้ำทุกครั้ง
หน้าลูกค้าลูกค้ายังเห็นข้อมูลบัญชีเป็นข้อความอ่านง่าย พร้อมปุ่มคัดลอกเลขบัญชี ไม่ต้องเลือกธนาคารเอง และไม่มี dropdown โผล่ในหน้าลูกค้า
ใบเสนอราคาก่อนแก้ราคาเมื่อมีบิลแรก ระบบสร้างใบเสนอราคาจากยอดเดิมและรายการเดิมให้ตรวจสอบได้ทันที โดยหัวร้าน ตารางสินค้า และยอดรวมอยู่ตำแหน่งถูกต้อง
ใบเสนอราคาหลังแก้ราคาหลังร้านแก้จำนวนหรือราคา ระบบสร้างใบเสนอราคาใหม่ตามยอดล่าสุด และส่งบิลสถานะกลับให้ลูกค้าด้วยข้อมูลที่อัปเดตแล้ว
ไม่ส่งใบเก่าซ้ำหลังแก้ราคา ระบบใช้ใบเสนอราคาชุดใหม่แทนชุดเดิม เพื่อไม่ให้ลูกค้าเปิดเจอยอดเก่าหลังร้านแก้บิลแล้ว
ย้ายมา OA จริงผ่านทดสอบบน LINE OA จริงแล้ว เมนูและหน้าร้านเปิดได้ตามที่ตั้งไว้ ลูกค้ากดจาก OA แล้วเข้าใช้งานร้านจริงได้
ผลลัพธ์รอบนี้หลังบ้านเลือกธนาคารได้ครบทั้งเลขบัญชีและ QR Code, ใบเสนอราคาก่อน-หลังแก้ยอดตรงกัน และช่องทางร้านจริงพร้อมใช้งาน

Dropdown เลขบัญชี เลือกธนาคารหลังบ้าน

ตั้งค่าบัญชีธนาคารเลือกได้จากรายการหลัก และยังมีตัวเลือกอื่นๆ สำหรับพิมพ์เอง

Dropdown QR Code เลือกธนาคารของ QR

QR Code ใช้รายการธนาคารชุดเดียวกันกับเลขบัญชี ทำให้ชื่อธนาคารในหลังบ้านสอดคล้องกัน

ก่อนแก้ราคา บิลเดิมยอด 952.00

ใบเสนอราคาก่อนแก้บิล แสดงจำนวนสินค้าและยอดรวมเดิมสำหรับตรวจเทียบ

หลังแก้ราคา บิลใหม่ยอด 714.00

หลังแก้บิล ระบบสร้างใบเสนอราคาใหม่ตามจำนวนและยอดล่าสุด พร้อมใช้ส่งกลับให้ลูกค้า

ย้ายมา OA จริงผ่าน เมนูร้านจริงพร้อมใช้งาน

ทดสอบบน LINE OA จริงแล้ว เมนูร้านและทางเข้าหน้าร้านพร้อมใช้งานกับลูกค้าจริง

ระบบค้นหาสินค้า + ระบบแจ้งรอบส่งอัตโนมัติ

รอบนี้เพิ่มระบบค้นหาสินค้าให้ลูกค้าหาของได้เร็วขึ้น พร้อมระบบแจ้งรอบส่งให้ลูกค้าทุกคนแบบอัตโนมัติ (ตั้งวัน-เวลาไว้ ระบบส่งเอง หรือกดส่งเองได้ทันที) และเก็บความปลอดภัยของหน้าเช็กสถานะออเดอร์

⌄
1. เพิ่มช่องคีย์เวิร์ดพิเศษ "แจ้งรอบส่ง" ในหลังบ้านเพิ่มกล่องตั้งค่าใหม่ในหน้าหลังบ้านแอดมิน (แท็บบอท) สำหรับตั้งวันที่ เวลา และข้อความแจ้งรอบส่ง พร้อมดูตัวอย่างข้อความก่อนส่งได้ในตัว
2. ระบบแจ้งรอบส่งอัตโนมัติตั้งวันและเวลารอบส่งไว้ล่วงหน้า พอถึงเวลา ระบบจะส่งข้อความแจ้งรอบส่งไปหาลูกค้าทุกคนที่เพิ่มเพื่อนใน LINE ให้เองอัตโนมัติ ไม่ต้องพิมพ์เองทุกครั้ง
3. ปุ่ม "ส่งเลยตอนนี้"ถ้าร้านมีรอบส่งกะทันหัน กดปุ่มส่งได้ทันทีหนึ่งครั้ง ข้อความจะถูกส่งหาลูกค้าทุกคนเลย มีหน้ายืนยันก่อนส่งกันกดพลาด
4. ข้อความสร้างให้อัตโนมัติแค่เลือกวันที่ ระบบจะเขียนข้อความให้เอง เช่น "มีรอบส่งวันศุกร์ที่ 29 พฤษภาคม 2569" โดยใส่ชื่อวันและวันที่ภาษาไทยให้อัตโนมัติ
5. เก็บความปลอดภัยหน้าเช็กสถานะปรับหน้าเช็กสถานะออเดอร์ให้แสดงชื่อ ที่อยู่ และรายการสินค้าของลูกค้าอย่างปลอดภัย ป้องกันปัญหาถ้าข้อมูลมีอักขระพิเศษปนมา
6. ระบบค้นหาสินค้าลูกค้าพิมพ์คำค้นแล้วเห็นรายการสินค้าแนะนำทันที พร้อมกดเลือกสินค้าได้ง่ายขึ้นจากหน้าร้าน

ระบบค้นหาสินค้า ค้นหาและแนะนำสินค้าแบบทันที

ภาพตัวอย่างหน้าร้านตอนค้นหาสินค้า ระบบแสดงรายการแนะนำตามคำที่พิมพ์

ระบบแจ้งรอบส่งอัตโนมัติ ตั้งเวลาและส่งข้อความให้ลูกค้าที่เพิ่มเพื่อนใน LINE ทั้งหมด

ภาพตัวอย่างหลังบ้านสำหรับตั้งวัน เวลา และข้อความแจ้งรอบส่ง พร้อมพรีวิวข้อความก่อนส่ง

อัปเดตหน้า Status / Checkout / Webhook

สรุปงานรอบนี้เป็นการเก็บรายละเอียดหน้าเช็กสถานะออเดอร์ หน้า checkout ระบบที่อยู่จัดส่ง ระบบระบุตำแหน่ง และความปลอดภัยของ webhook

⌄
1. โลโก้หน้าสถานะปลีก/ส่งถูกตั้งแต่ต้นหน้า status เลือกโลโก้ตามโหมดร้านตั้งแต่ช่วงแรกของการโหลด ทำให้ลูกค้าเห็นโลโก้ปลีกหรือโลโก้ส่งตรงกับลิงก์ที่เปิด
2. แก้ที่อยู่ ต.ต. / อ.อ. / จ.จ. ให้เหลืออย่างละอันปรับรูปแบบที่อยู่จากระบบแผนที่ ไม่ให้เติมคำนำหน้าซ้ำซ้อน เช่น ต.ต. อ.อ. จ.จ. เพื่อให้ที่อยู่จัดส่งอ่านง่ายและดูถูกต้อง
3. หน้า status โหลดดูดีขึ้น ไม่ดูค้างปรับหน้าระหว่างโหลดให้เป็นโครงร่างข้อมูลแทนการรอแบบนิ่ง ๆ ลูกค้าจึงเข้าใจว่าระบบกำลังดึงข้อมูลออเดอร์อยู่
4. ลิงก์สถานะร้านส่งพาเข้าโหมดร้านส่งถูกต้องปรับลิงก์จากการ์ด LINE ของร้านส่งให้พาเข้าหน้า status พร้อมโหมดร้านส่ง เพื่อให้หน้าเช็กสถานะแสดงข้อมูลและโลโก้ตรงช่องทาง
5. เพิ่ม Webhook Securityเพิ่มการตรวจสอบ LINE signature และ secret สำหรับ request ภายในระบบ ช่วยกัน request ที่ไม่ได้มาจากช่องทางที่กำหนด
6. ระบบระบุตำแหน่งทันทีหน้า Checkoutปรับปุ่มใช้ตำแหน่งปัจจุบันให้เรียกตำแหน่งจากแผนที่ได้เร็วขึ้น พร้อม fallback กรณีอุปกรณ์หรือเบราว์เซอร์ตอบสนองช้า

07

โครงข้อมูลบนชีต: Channel + AdminUsers

เพิ่มข้อมูลช่องทางออเดอร์ และเปลี่ยนระบบล็อกอินให้ควบคุมจากชีต ไม่ใช้รหัส 1234 ในโค้ดเหมือนเดิม

เพิ่มแล้ว

Orders เพิ่มคอลัมน์ Channel

สถานะตอนนี้: เก็บ Channel แล้ว เช่น “ปลีก” หรือ “ส่ง” แต่หน้าออเดอร์บนชีตยังเป็นออเดอร์รวม ยังไม่ได้จัดหน้าแยกปลีก/ส่งในชีต

AdminUsers Login ตามสิทธิ์ในชีต

เปลี่ยนจากเดิม: เดิมใส่ชื่ออะไรก็ได้ + รหัสจากโค้ด 1234 ตอนนี้ต้องใช้ Username/Password/Role ตามชีตเท่านั้น

ภาพรวมระบบ

  • ระบบใหม่ช่วยแยกร้านปลีก/ส่งโดยไม่ต้องสร้างเว็บซ้ำ
  • หลังบ้านมีสิทธิ์และช่องทางชัดเจน ลดออเดอร์ปนกัน
  • โหมดปิดปรับปรุงช่วยลดความเสี่ยงช่วง Dev แก้ระบบ

ระบบที่จะทำต่อ

  • ส่งบิลใหม่ที่เเก้ไขกลับ LINE ลูกค้า อัตโนมัติหลังแก้จำนวนสินค้า
  • ส่งบิลสถานะเเจ้งเตือนไปยัง LINE ลูกค้า อัตโนมัติหลังแก้สถานะ เช่น ส่งเเล้ว-กำลังจัดส่ง
  • ระบบกันสเเปมบอท
  • ระบบเปลี่ยนภาพเเบรนเนอร์สำหรับ ร้านค้าส่ง
  • การเเก้ไขสี เหลือง>ร้านขายส่ง/ชมพู>ร้านขายปลีก
  • การเเก้ช่องลูกค้าในหน้า ชำระเงิน ในเเต่ละร้าน จากเดิม จะเเสดงทั้งลูกค้าประจำเเละลูกค้าทั่วไป เเก้เป็น ร้านส่งก็จะมีเเค่ลูกค้าประจำที่มีในระบบ หรือ อาจจะมีลูกค้าใหม่ร่วมด้วย เเละ ร้านปลีกก็จะมีเเค่ลูกค้าทั่วไป การชำระ ของเเต่ละร้านตัดส่วน COD ออกเเละให้ชำระโอนจ่ายทันที เว้น เเค่มารับที่ร้านจะต้องจ่าย COD หรือจ่ายกับพนักงานโดยตรง
  • เพิ่มภาพริสเมณูในเเต่ละร้าน คนละสไตล์
  • จัดระเบียบหน้าออเดอร์ในชีตให้แยกปลีก/ส่งชัดขึ้น เเละตัดระบบส่วนเกินออก
  • ย้ายฐานไปยัง Line OA จริง
  • ทดสอบ flow จริงตั้งแต่ Rich Menu → สั่งซื้อ → หลังบ้าน → ชีต

ตารางอัปเดตงาน
